# Spacetime / 时空引力网 — 教学课件

基于**广义相对论**的三维时空可视化，浏览器直接运行，无需后端、无需构建。

这不是一部“引力模拟游戏”，也不是一张“橡皮膜时空”示意图。它的每一个画面元素都在表达一个物理量。

## 它在演示什么

- **空间因质量弯曲**：笛卡尔坐标网格在 *isotropic → Schwarzschild 面积半径* 坐标变换下的几何投影，中心处被径向拉伸，远处趋于平直。这不是“网格被力拉弯了”，而是弯曲度规下坐标本身的几何投影。
- **时间因引力变慢**：每个网格节点的局部时间因子 `dτ/dt = A(ρ)`，用三重编码表达——节点闪烁（越近中心越慢）、脉冲阵列（强场区被挤压）、累积色（中心长期绿、边缘转蓝）。
- **光子因逃离引力而变红**：从 `r ≈ 2 rₛ` 发射一批光子，沿近似零测地线的轨迹向外抛射；颜色按“发射钟与接收钟”的对比计算引力红移——频率越低越红，并轻微放大强调波长拉长。注意：光子自身频率沿静态度规的测地线守恒，变红是不同引力势处时钟的比较效应，不是“光途中变慢了”。
- **宇宙因膨胀而伸展**：FLRW 度规下“局部黑洞 + 全局宇宙”的视觉耦合——近场几乎不动，远场被 `smoothstep` 权重拉伸，让观众同时看到两种尺度。

## 物理公式

| 量 | 公式 | 说明 |
|---|---|---|
| Schwarzschild 半径 | `rₛ = 2GM / c²` | 只取决于质量 `M` |
| 时间因子 | `A(ρ) = (1 − rₛ/4ρ) / (1 + rₛ/4ρ)` | isotropic 坐标下的 `dτ/dt` |
| 网格空间映射 | `r = ρ·(1 + rₛ/4ρ)²` | isotropic → 面积半径坐标变换，再乘视觉阻尼系数控制观感 |
| 引力红移 | `f_obs / f_emit = A(r_emit) / A(r_obs)` | 发射势 vs 接收势 |
| 哈勃参数 | `H(a) = H₀·√(Ω_r/a⁴ + Ω_m/a³ + Ω_Λ)` | FLRW 宇宙学，Ω 之和 = 1 |

> **诚实声明**：光子轨迹的弯折为**弱场启发式偏折**，目标是直观感受而非数值天文精度（严格零测地线弱场偏折应为牛顿值的 2 倍）。本课件定位是教学可视化，不是求解器。

## 运行方式

- **在线演示**：https://LouisChenParfait.github.io/Spacetime-TimeFlow/
- **本地打开**：直接用浏览器打开 `index.html`（需联网，从 CDN 加载 Three.js）
- **交互**：拖拽 = 旋转；滚轮 = 缩放；Shift + 滚轮 = 调整宇宙膨胀速度

## 技术

- Three.js `0.160.0`（通过 `importmap` 从 CDN 引入）
- 单文件 HTML，无依赖、无构建步骤
